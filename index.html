Grafo de recomendação de produtos em C

O programa representa clientes e produtos de uma loja como um grafo e procura caminhos nele usando busca em profundidade (DFS) e busca em largura (BFS).

1. O problema

Uma loja online quer sugerir produtos com base no que clientes parecidos compraram. Se dois clientes compraram o mesmo produto, o que um deles comprou a mais pode ser uma boa sugestão para o outro.

No exemplo há 4 clientes (C1–C4) e 4 produtos (P1–P4). Cada aresta significa "esse cliente comprou esse produto":

C1 --- P1 --- C2 --- P3 --- C3 --- P4 --- C4
|
P2

As arestas são C1-P1, C1-P2, C2-P1, C2-P3, C3-P3, C3-P4 e C4-P4. O grafo é não direcionado e bipartido: toda aresta liga um cliente a um produto.

2. Como o grafo é guardado

Cada vértice vira um índice de 0 a 7, e os nomes ficam num vetor usado só para imprimir. As ligações ficam numa matriz de adjacência 8×8: adj[u][v] = 1 quando existe aresta entre u e v.

#define N 8
static const char *NOMES[N] = {"C1", "C2", "C3", "C4", "P1", "P2", "P3", "P4"};
static int adj[N][N];

static void montar_grafo(void) {
    static const int arestas[][2] = {
        {0, 4}, {0, 5}, {1, 4}, {1, 6}, {2, 6}, {2, 7}, {3, 7}
    };
    for (i = 0; i < sizeof arestas / sizeof arestas[0]; i++) {
        adj[arestas[i][0]][arestas[i][1]] = 1;
        adj[arestas[i][1]][arestas[i][0]] = 1;
    }
}

Como o grafo não é direcionado, cada aresta é marcada duas vezes. A matriz resultante:

      C1 C2 C3 C4 P1 P2 P3 P4
C1  [  0  0  0  0  1  1  0  0 ]
C2  [  0  0  0  0  1  0  1  0 ]
C3  [  0  0  0  0  0  0  1  1 ]
C4  [  0  0  0  0  0  0  0  1 ]
P1  [  1  1  0  0  0  0  0  0 ]
P2  [  1  0  0  0  0  0  0  0 ]
P3  [  0  1  1  0  0  0  0  0 ]
P4  [  0  0  1  1  0  0  0  0 ]

As duas buscas guardam o resultado na mesma struct, o que permite usar uma função só para imprimir:

typedef struct {
    int visitado[N];
    int ordem[N];      /* v na ordem em que foram visitados */
    int qtd_visitados;
    int arestas;       /* a para avancar a vertices novos */
    int caminho[N];    /* caminho origem p/ objetivo */
    int tam_caminho;
    int encontrado;
    int pilha[N];      /* caminho atual da recursao (DFS) */
    int topo;
} Busca;

4. Busca em profundidade (DFS)

A DFS escolhe um vizinho ainda não visitado e segue por ele o mais fundo possível. Quando um ramo termina sem chegar ao objetivo, a função retorna e o laço tenta o próximo vizinho. Esse "voltar e tentar outro" é o backtracking.

A pilha guarda o caminho atual: o vértice entra ao ser visitado e sai (topo--) quando nenhum dos seus vizinhos leva ao objetivo. Quando o objetivo é encontrado, o conteúdo da pilha já é o caminho da origem até ele.

static int dfs(int u, int destino, Busca *b) {
    int v;
    b->visitado[u] = 1;
    b->ordem[b->qtd_visitados++] = u;
    b->pilha[b->topo++] = u;

    if (u == destino)
        return 1;

    for (v = 0; v < N; v++) {
        if (adj[u][v] && !b->visitado[v]) {
            b->arestas++;
            if (dfs(v, destino, b))
                return 1;
        }
    }

    b->topo--;
    return 0;
}

5. Busca em largura (BFS)

A BFS visita primeiro todos os vizinhos da origem, depois os vizinhos deles, e assim por diante, em camadas. Para isso usa uma fila num vetor com dois índices: ini (próximo a sair) e fim (onde entra o próximo).

Cada vértice descoberto guarda em pai[v] de onde veio. Ao achar o objetivo, o programa segue os pais de trás para frente e depois inverte, obtendo o caminho com menos arestas.

while (ini < fim) {
    u = fila[ini++];
    b->ordem[b->qtd_visitados++] = u;

    if (u == destino) {
        b->encontrado = 1;
        break;
    }

    for (v = 0; v < N; v++) {
        if (adj[u][v] && !b->visitado[v]) {
            b->visitado[v] = 1;
            pai[v] = u;
            b->arestas++;
            fila[fim++] = v;
        }
    }
}

if (b->encontrado) {
    for (x = destino; x != -1; x = pai[x])
        tmp[k++] = x;
    b->tam_caminho = k;
    for (i = 0; i < k; i++)
        b->caminho[i] = tmp[k - 1 - i];
}

O que muda entre as duas

As duas chegam ao mesmo caminho, mas por ordens diferentes. A DFS foi direto por P1 e nunca precisou olhar P2. A BFS, antes de avançar, visitou todos os vizinhos de C1, inclusive P2. Por isso ela visitou um vértice e usou uma aresta a mais.

BuscaVisitadosArestasCaminho até P4
DFS65C1 → P1 → C2 → P3 → C3 → P4
BFS76C1 → P1 → C2 → P3 → C3 → P4

No contexto da loja, um caminho como C1 → P1 → C2 → P3 vira uma sugestão: C1 e C2 compraram P1, e C2 também comprou P3, então P3 pode ser recomendado para C1.
