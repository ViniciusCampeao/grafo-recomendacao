# Grafo de recomendação de produtos em C

Site: https://grafo.kernel-cloud.online

Grafo de clientes e produtos com busca em profundidade (DFS) e busca em largura (BFS).

## Compilar e executar

```
gcc -std=c99 -Wall -Wextra -pedantic -o grafo grafo.c
./grafo
```

## Deploy

Todo push na `main` compila o programa e publica o site automaticamente na minha VPS particular.
